01 / API EXPORT

Direct file export

Uses the Drive API to export Docs, Sheets, Slides as PDFs and download raw files. Respects file-level permissions on your account.

02 / VIEWER RECOVERY

Restricted file capture

When "Download" is disabled, the viewer still renders pages as images in your browser. The toolkit captures those rendered images and assembles them into a PDF — recovering content the UI won't let you download directly.

BLOB IMAGE CAPTURE
◈
03 / LOCAL PDF

Built in your browser

PDF assembly happens entirely client-side. No images are uploaded to a server. The toolkit reads what's already on your screen and writes the file to your disk.

100% CLIENT-SIDE
ⓘ
HOW PERMISSIONS WORK

Respects your access. Outsmarts the UI.

The toolkit uses your authenticated Google session to check what you can access. If the API allows a direct export, it takes the fast path. If the download is restricted, it falls back to recovering the content the viewer already rendered for you — the same content you're looking at on screen. It doesn't access files your account can't see, but it won't stop just because Google hid the download button.
